# كوثر (Kawthar) - تطبيق المصحف - خطة المشروع

**الهدف:** تطبيق مصحف أوفلاين فيه خطة ختمة ذكية. يبدأ بأندرويد ثم PWA.
**الأدوات:** Flutter + SQLite (مجاني بالكامل).
**النية:** صدقة جارية، بدون إعلانات.

## الميزات اللي اخترناها
- المصحف + البحث عن آية ومعرفة سورتها
- خطة الختمة + تذكير بعد كل صلاة
- وضع الزحمة (ورد خفيف في فترات الانشغال)
- مراجعة الحفظ (نظام Leitner)
- أوفلاين وخفيف
- مواقيت الصلاة

## معادلات
- صفحات اليوم = الصفحات الباقية × وزن اليوم ÷ مجموع أوزان الأيام الباقية
- أوزان الأيام: إجازة 2، عادي 1، زحمة 0.5

## الجداول الأساسية
- `ayahs`: الآيات
- `khatma_plan`: الخطة
- `busy_periods`: فترات الزحمة
- `memorized`: المحفوظ ومرحلة المراجعة
